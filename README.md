# Classificacao-de-musicas-do-Spotify
Este projeto consiste em fazer um modelo preditivo supervisionado para poder definir o valor da coluna de valência de uma música(quanto mais perto de 1 mais animada, quanto mais perto de 0 mais lenta a música é).

Used technologies:
- Pandas
- Matplotlib
- Sklearn
- Seaborn
- Numpy
